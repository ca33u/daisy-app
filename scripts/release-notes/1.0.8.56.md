# Daisy 1.0.8.56

- **With nothing open, the day card no longer makes up people and work.** The intro at the top of the day card on Home is written by your summary provider, and with no open items the model could fill it with people and overdue reports that don’t exist. Now, with nothing open, no model is asked, the card shows your meetings, and the calendar isn’t sent to a cloud provider for it. Apple Intelligence doesn’t write the intro any more: in our tests it also tied real tasks to people who don’t exist and called them overdue. With other providers the request no longer asks for people and overdue promises. An intro saved by an earlier version isn’t shown. Reported by Brandon Kraft on GitHub
- **An intro being written is dropped when the day changes under it.** If the number of meetings or open items changes while it is being written, or the card moves on to tomorrow, Daisy asks again, so an answer about today doesn’t land over tomorrow’s meetings, and such a change no longer leaves the card without an intro. Turning off «Morning brief» drops a request in progress
- **Permission to send the morning brief is now per cloud provider.** One yes used to cover every cloud provider you picked later. Now Daisy asks about each one separately. The yes you gave stays with the cloud provider selected at the first launch after the update; if a local one is selected then, Daisy asks again when you switch to a cloud one
- **In Settings, the search field sits on one line with the page’s title**
