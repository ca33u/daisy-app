# Daisy 1.0.8.7

- **Settings → Permissions shows System Audio Recording** — allowed, not allowed or not asked yet — with a way to allow it or check again. Screen Recording is now the fallback it is.
- **The audio diagnostics meters no longer freeze.** Changing a setting on that screen could leave the microphone meter stuck on an old level while the microphone was fine.
- **If the system-audio capture starts silent, Daisy restarts it** — for example when headphones switch to call mode at the very moment a recording starts.
- **Voice Memos import has moved to Daisy for iPhone.** On the Mac the import, its settings and the Full Disk Access request are gone; recordings imported earlier stay where they are.
- The Permissions screen drops its "Optional" badges.
