# Daisy 1.0.8.45

- **Три новых провайдера саммари: YandexGPT, GigaChat и DeepSeek.** Каждый работает на твоём ключе: YandexGPT — ключ API Yandex AI Studio и ID каталога, GigaChat — ключ Foundation Models в cloud.ru, DeepSeek — ключ API DeepSeek. Выбери в «Настройки → ИИ → Провайдер саммари»; модели с длинным контекстом справляются со встречами на несколько часов.
- **Облачное саммари больше не оплачивается дважды.** Если провайдер долго не начинает отвечать, Daisy не отправляет тот же запрос снова — раньше это могло списать деньги за одно саммари до трёх раз.
- **Отменённое саммари не считается сбоем.** А если провайдер не уложился во время, в сообщении видно, не ответил ли он вовсе или оборвался на середине.
