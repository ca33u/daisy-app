# Daisy 1.0.8.2

- **System audio no longer gives up in the middle of a meeting.** When macOS stops the capture stream, Daisy restarts it — and keeps doing so for the whole recording, backing off only if it dies several times within two minutes. Before, the third stop ended system capture for good and the rest of the meeting kept only your microphone.
- **If the other side is lost, you are told where you are looking.** A notification and a pill appear every time, with a **Restart capture** button; the warning stays until you close it, and Daisy says so when the sound comes back.
- **Bluetooth headphones:** if system audio delivers nothing at all in the first 35 seconds, Daisy says so right away and suggests switching output to the speakers or wired headphones.
- **Repetition loops are removed from the live transcript** — a phrase going round («I know that I know that I know…»), or a run of the same short line like "Thank you." after a call has ended. Real repetition in speech is left alone.
- **A new recording no longer cancels the previous one's final pass.** It is queued and runs a minute later.
- **An update never ends a recording.** Background checks wait while you record, and an update set to install on quit is offered when nothing is recording — a menu-bar app is rarely quit, so the fixes used to never arrive.
- Release notes and the update window speak Russian; the menu-bar widget shows a failing system-audio source with a warning mark, not colour alone; small captions are easier to read.
