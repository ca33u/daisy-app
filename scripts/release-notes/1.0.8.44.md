# Daisy 1.0.8.44

- **The meeting model loads even when Daisy can’t open Documents.** Part of the model used to live in ~/Documents; with access to that folder denied, the model never loaded and downloading it again didn’t help. Everything now stays in Daisy’s own folder.
- **Dictation doesn’t wait for the meeting model.** On Faster or Apple dictation, the key starts right away. If a model is still getting ready, the widget shows how far along it is — and letting go of the key cancels instead of spinning until the model is done.
- **Intel Macs no longer crash.** The speech model for meetings doesn’t run on Intel yet: meetings and voice notes now say they need a Mac with Apple silicon, and dictation runs on Faster.
- **Clearer log reports.** A report now names the Mac model and what Daisy knows about the System Audio Recording permission, so a meeting that recorded only your voice is easier to explain.
