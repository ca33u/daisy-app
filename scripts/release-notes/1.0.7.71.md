# Daisy 1.0.7.71

- First launch now ends with model preparation. Choose a speech model, download the required models and wait for Daisy to check them before starting your first recording. An interrupted setup resumes after reopening the app.
- Speech models must pass a real on-device recognition check before Daisy calls them ready. Empty model folders, missing weights and download placeholders no longer count as a complete installation.
- A failed speech model can be downloaded again from Settings → Transcription. Daisy keeps the previous files for diagnostics and offers log export; existing recordings and notes remain accessible.
- Disk checks account for the selected Whisper model and temporary download space. Additional speech-model downloads also check free space, while loading an already downloaded Whisper model no longer requires the full download budget.
- Recording buttons, shortcuts and calendar starts cannot begin a session before setup or model preparation is complete. A model problem opens the preparation settings with a clear explanation.
