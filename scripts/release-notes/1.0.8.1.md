# Daisy 1.0.8.1

- **Fixes a slow first launch after updating.** 1.0.8 asked the old macOS keychain for every saved key while starting up, which on some Macs — a profile moved from another machine, restored from a backup, or an earlier build of Daisy — made the system show a permission dialog before the window appeared, and Daisy stood still until it was answered. Daisy now starts without touching the old keychain: keys that still live there are fetched afterwards, with the app already on screen.
- Everything from 1.0.8: sync with Daisy for iPhone (off by default), speakers for phone recordings, shared folders, `.daisy` export, photos added later, one button vocabulary.
