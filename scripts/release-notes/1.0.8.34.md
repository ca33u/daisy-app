# Daisy 1.0.8.34

- **A local summary model in one click.** Settings → Summary → Ollama now lists the models, says which one fits your Mac's memory, and downloads it with a progress bar and a Cancel — no Terminal. If Ollama isn't installed, one button opens its download page and the list appears by itself once it's running. The model comes from ollama.com once and stays on your Mac; the transcript never leaves it.
- **Record never waits any more.** Starting a recording while Daisy is still transcribing a stored file or finishing the previous meeting now pauses that work and starts right away; it continues after the recording, and a toast says so.
- **Apple Intelligence and a language it can't write.** A meeting in Russian (or another language Apple's model doesn't write) used to get no summary and no explanation. Now the recording says why and offers "Choose another provider", and Settings → Summary warns before the first recording.
- **Bluetooth headsets on long calls.** When a headset switches into call mode and back, Daisy checks that it still hears the other side and recovers if it doesn't. If the headset is your Mac's input, a one-time hint shows how to keep it from switching: pick the built-in microphone in System Settings → Sound → Input.
- **The previous meeting's final pass starts the moment it can,** not up to a minute later.
- **Send Log Report explains more:** each recording keeps its own log excerpt next to it, so a report sent hours later still has the call; the report also says what the last update check saw.
- Apple's speech model is asked for once a day after a failed download, not at every recording start; a screen-text pass that Vision refuses on some frames says how many.
