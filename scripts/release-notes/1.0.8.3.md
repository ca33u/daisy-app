# Daisy 1.0.8.3

- **The menu-bar flower is smaller inside its disc** and rests with a white centre — the same flower, with room around it. While recording the centre is orange, as on the iPhone and the watch.
- **"Daisy" in dictation** is written as Daisy when it is heard as «Дейзи» or «Дэйзи».
- **Loop filter, fixed:** a real short reply right next to a repeated phrase (a «Да, да.» before «Музыка.» ×28) is no longer thrown away with it.
- **Sessions from Daisy for iPhone keep their kind** when you move them between folders — rehearsal takes stay rehearsal takes.
- Privacy protection for cloud summaries now runs on the same code as the iPhone; what it replaces is unchanged.
