# Daisy 1.0.8.57

- **The other side of a call is recorded at its real speed.** In a call with AirPods, the other side could be written at half speed: their part came out twice as long as the meeting, and speech was transcribed as words in another language. With some output devices it ran several percent too fast or too slow instead. This concerns recording through System Audio Recording; recording through Screen Recording wasn’t affected. Daisy now takes the speed from the audio device the recording runs on, usually the Mac’s own speakers, and checks it while recording. Meetings recorded before stay as they are. If that device changes its sample rate during a recording, the next 3–4 seconds can be at the wrong speed, and what follows can be shifted by a few seconds. Not yet tried in a call with AirPods on our side
- **A connected ChatGPT account no longer looks as if it weren’t set up.** After a launch or an update, Home could ask for a summary provider although one was connected, and until you opened Settings, meetings that ended were left without a summary. Now a check that fails doesn’t count as «not set up»: Daisy repeats it a few times, and Settings shows «Couldn’t check» meanwhile. If there is still no answer, it asks again when a recording starts and before the summary, and tries to write the summary anyway. Summaries set for the end of the day wait until the check works
- **With your ChatGPT account chosen for summaries, a summary no longer goes out if Codex is signed in with an API key.** The account is checked right before the text is sent
- **A provider that wasn’t ready is asked again when a recording starts.** LM Studio, the local model and others you have started since are noticed, not only Ollama. An expired ChatGPT session is recognised with the Russian interface too, and being offline is no longer taken for one
- **Imported audio is no longer deleted with Daisy’s recordings.** An imported .caf file was kept under the same name as Daisy’s own audio, so once it had a transcript it was removed by «Audio storage» set to 24 hours, 7 or 30 days, and by «Delete audio files» in Settings. Now both leave imported audio alone. The trash button next to a meeting’s audio still moves it to the Trash
