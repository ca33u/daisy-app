# Daisy 1.0.8.45

- **Three new summary providers: YandexGPT, GigaChat and DeepSeek.** Each runs on your own key — YandexGPT with a Yandex AI Studio API key and folder ID, GigaChat with a cloud.ru Foundation Models key, DeepSeek with a DeepSeek API key. Pick one in Settings → AI → Summary provider; the long-context models take meetings of several hours.
- **Cloud summaries never bill twice for one answer.** If a provider takes too long to start answering, Daisy no longer sends the same request again — that could charge you for the same summary up to three times.
- **A cancelled summary isn’t counted as a failure.** And when a provider times out, the message now says whether it never answered or stopped halfway.
