# Daisy 1.0.8.24

- **Long meetings get their summary.** Cloud summaries (Anthropic, OpenAI, Kimi, Gemini) now stream, so a two-hour meeting no longer times out and is not billed twice for a retry.
- **A missing summary says why.** If the summary didn't come — Apple Intelligence switched off, a language it doesn't write yet, a provider error — you get a notice with a link to Summary settings, and the meeting keeps a note with Try again.
- **Processing plans.** Settings → General has a simple choice between lighter and fuller processing, and meetings can wait to be processed until the Mac is on a charger. A meeting processed later now gets everything a normal one does: corrected names and terms, speaker-name suggestions, text from the screen and your marked moments in the summary.
- **Summary progress** shows while the summary is being written; long meetings show the summary first and correct the transcript after.
- **Gemini** is a new summary provider.
- **Notes have a default project**, like meetings.
- **The keyboard layout fix has one switch**, off by default; its shortcut leaves real words alone and Fn no longer triggers it.
- **MCP connections without Node.js.** Claude and Codex connect through a built-in bridge; Claude Code connects in one click.
- **Send logs** attaches the report in Apple Mail; with another mail app it saves the report and opens a filled-in message.
- **Audio settings** no longer list Daisy's own capture device among microphones and outputs.
- **The Russian interface uses «ты».**
