# Daisy 1.0.8.49

- **Диктовка больше не ждёт Parakeet после запуска.** Если ты диктуешь через Parakeet и модель уже скачана, Daisy теперь загружает её при старте: первая диктовка после обновления или перезапуска не застревает на «Загружаю модель речи». Нажмёшь, пока модель ещё грузится, — диктовка дождётся загрузки. Когда Маку критически не хватает памяти, Daisy выгружает модель, а при следующей диктовке снова загружает её с диска.
- **Grok для саммари.** Выбери Grok в «Настройки → ИИ → Провайдер саммари» и вставь API-ключ xAI. По умолчанию Grok 4.3: около $0,03 за час встречи; есть и Grok 4.7 — лучше, но дороже. Daisy просит xAI не сохранять ответы, а после первого саммари Настройки показывают, включён ли у твоей команды в xAI Zero Data Retention: без него xAI хранит запросы 30 дней для проверки на злоупотребления.
- **Cursor: модель из списка Cursor.** Рядом с полем «Модель» появилась кнопка «Выбрать» с моделями, которые даёт твой план Cursor; любой ID модели можно по-прежнему вписать вручную. А ещё Настройки предупреждают: если Privacy Mode выключен, Cursor может хранить транскрипты и обучать на них свои модели, — и подсказывают, где его включить.
