# Daisy 1.0.8.6

- **Проверка разрешения работает и в Bluetooth-наушниках.** Daisy проверяет, можно ли ей записывать системный звук, по тону, которого никто не слышит. Теперь этот тон играет на собственном выходе Мака, и наушники в режиме звонка больше не заставят проверку ошибочно показать «не разрешено».
- Уведомление об обновлении — без точки в конце.

Также в этой сборке, из 1.0.8.5: собеседники записываются и в Bluetooth-наушниках; Daisy один раз просит «Запись только системного звука» в своём окне; если способ, которым Daisy слушает, замолкает, она пробует другой в той же записи; короче предупреждение, когда собеседников не слышно.
