# Daisy 1.0.8.7

- **В Настройках → Разрешения появилась «Запись системного звука»** — разрешено, не разрешено или ещё не спрашивали — с кнопкой, чтобы разрешить или проверить снова. «Запись экрана» теперь подписана как запасной путь.
- **Индикаторы в диагностике аудио больше не замирают.** Смена настройки на этом экране могла оставить индикатор микрофона на старом значении, хотя микрофон работал.
- **Если захват системного звука стартовал беззвучным, Daisy перезапускает его** — например, когда наушники переходят в режим звонка ровно в момент начала записи.
- **Импорт Диктофона переехал в Daisy для iPhone.** На Маке убраны импорт, его настройки и запрос полного доступа к диску; импортированные раньше записи остались на месте.
- На экране разрешений больше нет бейджей «Необязательно».
