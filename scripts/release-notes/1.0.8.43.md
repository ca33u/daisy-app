# Daisy 1.0.8.43

- **Settings are eight questions now.** General, Shortcuts, Meetings, Dictation, AI, Library, Connections, Privacy — each tab answers one thing. Search at the top (⌘F) finds any row by name, and every link into Settings now lands on the exact row and lights it up.
- **All shortcuts in one place.** Shortcuts holds every key, including the layout fix; the Daisy key's cloud consents sit with it.
- **The processing plan says what it owns.** Rows a plan controls carry a “set by plan” badge; change one by hand and the plan becomes Custom instead of quietly drifting.
- **Updates, crash reports and “Help make Daisy better”** moved from About into Settings — Updates under General, what leaves your Mac under Privacy. Calendars live in Connections.
- **The other side after a Bluetooth headset leaves call mode.** When AirPods switch from a call back to music, the capture is rebuilt from scratch — and, if that stays silent, moved to the current output — instead of giving up with only your voice.
- **Smoother while transcribing live.** Whisper's decoding runs off the main thread, so dialogs and buttons no longer stutter during a pass.
