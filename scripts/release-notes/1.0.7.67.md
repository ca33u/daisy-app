# Daisy 1.0.7.67

- **Connections moved into Settings.** Notion, the MCP server and auto-routing now live under Settings → Connections instead of taking up a sidebar row — they're set up once and rarely revisited.
- **The live dictation caption sits level with the flower.** It used to float one slot above the widget; now it's centred on it, and only steps aside when another prompt is showing at the same time.
- **Apple's speech engine can't be chosen for a language it doesn't support.** The option is greyed out with the reason, and an existing Apple selection under such a language falls back to Whisper — the engine that was doing the work all along.
- **Clearer diagnostics.** A failed connection to an MCP summary provider now names the server it couldn't reach, and releasing the dictation key no longer logs a spurious error.
