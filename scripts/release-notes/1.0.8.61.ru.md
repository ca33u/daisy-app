# Daisy 1.0.8.61

- **Из окна «Что нового» проще выйти.** Круглый крестик в правом верхнем углу фото, а «Не сейчас» теперь отдельная кнопка прямо под «Оформить подписку»; раньше это была строчка мелкого текста под пояснениями. Esc по-прежнему закрывает окно
- **Одна подписка на Mac и iPhone.** Новый пункт в «Что нового»: подписка принадлежит аккаунту Daisy, поэтому работает на любом Mac с твоим аккаунтом, а когда выйдет Daisy для iPhone, будет работать и в нём
- **Тексты «Что нового» вычитаны.** Если ты в аккаунте, строка о бесплатных саммари пока переключатель «Писать саммари по подписке Daisy» выключен, говорит, что его нужно включить: сам по себе вход ничего не пишет. Строка о продлении сразу говорит, где отменить подписку
- Если окно «Что нового» уже открывалось на 1.0.8.60, само оно больше не откроется: новое окно — в меню «Справка → Что нового в Daisy»
- По-прежнему не проверено вживую: настоящий платёж, саммари по подписке и «Исправлять диктовку по контексту» на настоящем запросе
