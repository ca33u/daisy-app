# Daisy 1.0.8.51

- **Daisy closing right after launch.** Since 1.0.8.49, with Parakeet as your dictation model, Daisy loaded the Parakeet and Whisper models at the same moment when it started, and we received a report of it closing right then, twice on one Mac. The two now load one after the other: Parakeet first, then Whisper
- **Daisy recovers when loading a model closes it.** If Daisy closes unexpectedly while it is loading a speech model, the next launch clears its cache of compiled models and doesn’t load them ahead of time; they are built again the first time you record or dictate, which takes longer once. The first launch of this version clears that cache too when it knows the run before it ended in a crash. If Daisy closes unexpectedly twice in a row while loading the same model, it stops loading that model on its own and says so in Settings, where «Download and check» tries again
