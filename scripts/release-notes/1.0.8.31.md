# Daisy 1.0.8.31

- **Your voice and the others' line up.** The microphone and system-audio recordings now start on one clock, so an exported file — mixed or as two tracks — no longer has the two sides drifting apart. Recordings made before this version stay as they were.
- **The daisy stands upright again** in the app icon, the menu bar and the widget; the petals still curve while Daisy prepares or stops a recording.
- **The widget reacts more to your voice**, and evenly on both sides — it no longer looks as if it sways left and right.
- **With live transcription set to "After the meeting"**, the recording window says the transcript will appear after the meeting instead of "Listening…".
