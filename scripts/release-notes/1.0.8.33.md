# Daisy 1.0.8.33

- **Help make Daisy better — if you want to.** Daisy asks once whether it may send a short daily summary of which features ran and where something went wrong. Numbers only: no text, titles, names or identifier, so we never know who you are. "See What's Sent" shows the report word for word; About → Help improve Daisy turns it on or off. Every counter is listed in the source.
- **Dictation history keeps as long as you choose:** 24 hours, 7 days (the new default), 30 days or always. "Paste last dictation" pastes only a dictation from the last hour.
- **Imports know what's already there.** A file already in the Library says so and is left out unless you tick "Import again". Quitting while Daisy copies an import or transcribes stored audio asks first.
- **iCloud sync is safer:** an edit made on another device at the same moment is no longer overwritten, and a relaunch no longer downloads everything again.
- **A next step you only shared stays open.** Sending it to participants, a tracker or an assistant no longer counts it as done.
- iPhone recordings waiting for speaker separation survive a relaunch; leftover hidden copies from a killed import are cleaned up; Russian text fixed throughout.
