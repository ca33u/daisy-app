# Daisy 1.0.8.24

- **Длинные встречи получают саммари.** Облачные саммари (Anthropic, OpenAI, Kimi, Gemini) теперь приходят потоком: двухчасовая встреча больше не обрывается по таймауту и не оплачивается дважды из-за повтора.
- **Если саммари нет — видно почему.** Apple Intelligence выключен, не пишет на этом языке, провайдер ответил ошибкой — появляется уведомление со ссылкой на настройки саммари, а у встречи остаётся пометка с кнопкой «Повторить».
- **Планы обработки.** В Настройках → Основные — простой выбор между лёгкой и полной обработкой, а встречи можно обрабатывать позже, когда Mac на зарядке. Отложенная встреча теперь получает всё, что обычная: исправленные имена и термины, подсказки имён говорящих, текст с экрана и отмеченные моменты в саммари.
- **Прогресс саммари** виден, пока оно пишется; у длинных встреч сначала саммари, потом уточнение транскрипта.
- **Gemini** — новый провайдер саммари.
- **У заметок есть проект по умолчанию**, как у встреч.
- **Исправление раскладки включается одним переключателем**, по умолчанию выключено; сочетание клавиш не трогает настоящие слова, Fn его больше не вызывает.
- **MCP-подключения без Node.js.** Claude и Codex подключаются через встроенный мост, Claude Code — в один клик.
- **«Отправить логи»** прикладывает отчёт в Apple Mail; с другой почтой сохраняет отчёт и открывает заполненное письмо.
- **В настройках звука** среди микрофонов и выходов больше нет собственного устройства захвата Daisy.
- **Интерфейс на русском обращается на «ты».**
