# Daisy 1.0.8.40

- **⌃⌥Space and ⌃⌥V no longer start a note too** when the Daisy key is ⌃⌥: another Daisy shortcut pressed through it cancels the Daisy key.
- **«Write a reply» over a message selected in Mail** now sees the message (and text selected on web pages generally). If there's still nothing to answer, Daisy says so instead of showing a reply made of [?].
- **The result card** is dark like the widget, and appears next to the widget instead of at the mouse.
