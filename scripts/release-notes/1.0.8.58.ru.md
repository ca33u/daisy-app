# Daisy 1.0.8.58

- **Подписка Daisy: саммари без своего API-ключа.** Новый провайдер в «Настройки → ИИ». Саммари и шаблоны, бриф перед встречей и утренняя сводка, второй проход по транскрипту, имена спикеров, «Что я пропустил?», переписывание в твоём стиле, «Мой стиль» и команды клавиши Daisy работают на Claude через сервер Daisy; сервер передаёт текст в Anthropic и не хранит его. Разбор плана встречи по-прежнему работает только с OpenAI. Запись, расшифровка и все провайдеры, которыми ты уже пользуешься, работают как раньше, без аккаунта
- **Для неё нужен аккаунт Daisy.** Вход по коду из письма или через Google. Перед первым входом Daisy спрашивает, можно ли отправлять текст через её сервер, и без «да» ничего не отправляет. Имена и контакты заменяются перед отправкой, только если в Настройках включено «Защищать чувствительные данные перед облачным ИИ». Вход хранится на этом Маке и не синхронизируется через iCloud. Там же можно выйти или удалить аккаунт; удаление не отменяет платную подписку. Входа через Apple на Маке пока нет
- **Три саммари встреч бесплатны для каждого аккаунта.** Они пишутся стандартным саммари Daisy, без твоих шаблонов. Остальные задачи требуют подписки
- **$7,99 в месяц или $59,99 в год, оформляется из Настроек.** Daisy открывает оплату в браузере, платёж идёт через Whop, и подписка появляется в Настройках, когда оплата подтверждена. Она принадлежит аккаунту, а не этому Маку: войди на другом Маке, и она заработает там. У использования есть дневной и месячный лимит; когда он исчерпан, саммари об этом говорит, а транскрипт остаётся. На живом сервере это ещё не проверено: ни вход из приложения, ни саммари, ни настоящий платёж
- **Разбор плана через Codex только на аккаунте ChatGPT.** Если Codex вошёл по API-ключу, план встречи больше не уходит по этому ключу, как уже не уходили саммари
- **«Удалить аудиофайлы» в Настройках говорит, что именно удаляется.** Аудио расшифрованных записей; импортированное аудио и записи без транскрипта остаются
