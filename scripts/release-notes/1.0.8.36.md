# Daisy 1.0.8.36

- **The Daisy key on ⌃⌥.** On a new install the Daisy key is ⌃⌥ held on its own, no letter. In Settings → Recording → Shortcuts you can pick ⌃⌥, the right ⌘, ⌃⌥D or ⌃⇧D; a key you already have stays as it is. Daisy's own ⌃⌥⌘ shortcuts and window managers' ⌃⌥-arrows don't set it off, and another key pressed during a hold cancels it. On a key with a letter, the letter no longer reaches the app you're in.
- **Start a long note with «to project Landing»** and it goes to that project. Daisy checks again on the final transcript, so a name the live transcript missed still counts.
- The Daisy key's start sound plays only once you're holding it, not on a tap.
