# Daisy 1.0.8.1

- **Исправлен медленный первый запуск после обновления.** Версия 1.0.8 при старте спрашивала у старой связки ключей macOS каждый сохранённый ключ. На некоторых Маках — с профилем, перенесённым с другой машины, восстановленным из резервной копии или оставшимся от прежней сборки Daisy — система показывала запрос разрешения ещё до появления окна, и Daisy стояла, пока на него не ответят. Теперь запуск не трогает старую связку: ключи, которые всё ещё лежат там, забираются потом, когда приложение уже на экране.
- Всё из 1.0.8: синхронизация с Daisy для iPhone (по умолчанию выключена), спикеры для записей с телефона, общие папки, экспорт `.daisy`, фотографии, добавленные позже, словарь одной кнопкой.
