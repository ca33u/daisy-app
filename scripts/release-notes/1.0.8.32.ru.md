# Daisy 1.0.8.32

- **Отчёты о сбоях — только если ты их отправишь.** Если Daisy неожиданно закроется, при следующем запуске она спросит, отправить ли отчёт разработчику, и сначала покажет его целиком: где произошёл сбой, версии Daisy и macOS и модель Mac. Никогда — твои встречи, имена, файлы и устройства. Без твоего ответа ничего не уходит; вопрос можно выключить в «О приложении» → «Отчёты о сбоях».
- **Пауза больше не разводит голоса.** В записях с паузами твой голос и голоса собеседников в экспорте остаются синхронными.
- **Новые цвета виджета:** шалфейный центр в покое, оранжевый — встреча, сиреневый — диктовка, голубой — голосовая заметка, красный — ошибка; на паузе центр остаётся оранжевым, а лепестки становятся серыми.
- **GPT-6.1 Sol — модель OpenAI по умолчанию**: быстрее и дешевле GPT-5.6 Terra, которая осталась в списке. Расход токенов теперь учитывает запись в кеш OpenAI по её собственной цене.
