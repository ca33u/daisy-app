# Daisy 1.0.8.37

- **Что нового в Daisy.** После этого обновления откроется короткое окно: три анимированных шага про клавишу Daisy — нажатие для заметки сразу в нужный проект, удержание с командой, удержание молча, чтобы переписать выделенное. В нём твоя клавиша, а снова открыть его можно через «Справка → Что нового в Daisy». Если клавиша Daisy ещё не назначена, окно об этом скажет и откроет Настройки.
