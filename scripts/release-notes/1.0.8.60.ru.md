# Daisy 1.0.8.60

- **Сначала выбираешь тариф, потом оформляешь.** В «Настройки → ИИ» строка «Тариф» подписки Daisy была двумя кнопками с ценами, и нажатие на любую сразу открывало страницу оплаты. Теперь цены — это выбор, «$7,99 в месяц» или «$59,99 в год», сначала выбран месяц, а страницу оплаты для выбранного тарифа открывает отдельная кнопка «Оформить подписку» под ним. Рядом с кнопкой написано, что страница оплаты откроется в браузере
- **«Проверить саммари» на подписке Daisy показывается только подписчику.** Без подписки кнопка стояла серой, потому что проверка потратила бы одно из трёх бесплатных саммари; теперь строки нет, пока подписка не активна. Для своего провайдера ничего не изменилось
- Не проверено вживую: новая строка «Тариф» в запущенном приложении, где её пока рисовал только тест, и с VoiceOver; настоящий платёж; саммари, написанное по подписке
